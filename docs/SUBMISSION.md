## Before submission

1. Run the app personally and follow TECHNICAL-WALKTHROUGH.md. Confirm that you can explain the implementation and limitations honestly.
2. Record the actual running app using DEMO-SCRIPT.md, including the graph, a retrieved incident, the proposed code failing, and the corrected example passing. Show the optional live agent retrieval if entering the agent track; clearly distinguish deterministic analysis from model output.
3. Upload the recording to a publicly accessible video location and replace the pending video status here and in README with the real link. Check that judges can open it without requesting access.
4. Sign in at https://www.wemakedevs.org/hackathons/falkordb/submit and provide the repository, video, track, and other requested fields. Do not represent the static walkthrough as a live deployment or video.
