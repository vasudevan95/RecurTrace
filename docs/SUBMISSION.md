## Before submission

1. Run the app personally and follow TECHNICAL-WALKTHROUGH.md. Confirm that you can explain the implementation and limitations honestly.
2. Watch the published two-minute working demo. It shows the actual graph, incident retrieval, optional local AI tool call, proposed code failing, and corrected example passing. Captions distinguish deterministic analysis from model output.
3. Share the public release link above, or upload the supplied MP4 to YouTube as Unlisted if the submission form requires a streaming-video URL. Verify that judges can open your chosen link without requesting access.
4. Sign in at https://www.wemakedevs.org/hackathons/falkordb/submit and provide the repository, video, track, and other requested fields. Do not represent the static walkthrough as a live deployment or video.
